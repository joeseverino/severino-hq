Each row is an application.history.HistoryLine: an event (every row one operation wrote, named by the row about the operation itself), a row it changed, folded beneath it in the same columns (`under`), or a moment another source dated (a deploy, a container start), or a run of like moments read as one (`burst`, history.RUN), its moments folded beneath it. An event that changed things heads them (`data-folds`): its gutter holds the fold rather than the row's own toggle, so opening the fold opens what its columns that left hold too (tables.js). A fold carries at most history.SHOWN of what the event changed, a run at most as many moments; a last row (`rest`) counts the others and, for an event, links to its page, which lists every one. What a row names reads as an identifier where it is one (`readout`, cut at the region's cap); what a row says is text that breaks wherever it must (`cell-data`).
