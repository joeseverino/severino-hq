{% load static stylesheet_tags %}{% comment %} What a document's head holds so its first frame is drawn whole, in the theme it was chosen in: base.html's and every page the catalog draws alone. The theme is declared before the stylesheet arrives, so a chosen theme paints on the first frame without a script. `color-scheme` tells the browser which canvas to clear to while it waits; the theme colors tint its chrome and repeat the header surface in each palette (`--accent` light, `--surface` dark in css/app/tokens.css). A document drawn for no request (the Design page's gallery) has no THEME and follows the system's. The face the stylesheet asks for is fetched beside it so the first paint already has it: the stylesheet shows it only if it is ready (optional), so text never changes face, and therefore never moves, after it is drawn. Nothing is drawn until the content is parsed whole: Chromium may paint a partly parsed page, and a table's later rows, or a toolbar's later parts, would then widen what is already drawn. The target follows ``, since Chromium lets go once the element it names is inserted; a page with no such target is drawn once its parsing ends.
