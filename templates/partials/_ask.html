{% comment %} A "do this now" control, from `ask` (application.asks.Ask): a button, and how the work it last asked for stands. {% include "partials/_ask.html" with ask=ask %} The button posts and the request answers at once; the work happens outside it. Without script that is a form post back to this page, which draws the control as the stored state has it. With script the same post is answered in place and the control follows `data-ask-status` until the work ends, then fetches the part of the page `data-ask-refresh` names. Either way a page loaded while the work is live resumes following it. The note is the live region, and only a change of state changes it. The elapsed time ticks beside it, outside the region, so it is not read out every second. A busy button stays focusable (`aria-disabled`), so focus is not dropped by the thing the operator just pressed. {% endcomment %} {% ask_button ask extra %} {% if ask.standing.state != "idle" %}{{ ask.standing.note }}{% endif %}
