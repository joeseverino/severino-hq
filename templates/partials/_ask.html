{% comment %} A "do this now" control, from `ask` (application.asks.Ask): a button, and how the work it last asked for stands. {% include "partials/_ask.html" with ask=ask %} The button posts and the request answers at once; the work happens outside it. Without script that is a form post back to this page, which draws the control as the stored state has it. With script the same post is answered in place and the control follows `data-ask-status` until the work ends, then fetches the part of the page `data-ask-refresh` names. Either way a page loaded while the work is live resumes following it. The note is the live region, and only a change of state changes it: the state's word and its sentence, of which a table cell shows the word alone, since a sentence held to the width of its button would stand a word a line and make its row a column; there the sentence is the button's title, and the row's open line says the word and the sentence under the button's label (`data-ask-why`, kept by ask.js while the work moves). The elapsed time ticks beside it, outside the region, so it is not read out every second. A busy button stays focusable (`aria-disabled`), so focus is not dropped by the thing the operator just pressed. {% endcomment %} {% ask_button ask extra|default:"" %} {% if ask.standing.state != "idle" %}{{ ask.standing.label|breakable }}{{ ask.standing.note|breakable }}{% endif %} {% if ask.standing.state != "idle" and ask.standing.note %}{{ ask.standing.label|breakable:":" }} {{ ask.standing.note|breakable }}{% endif %}
