Radios and CSS rather than JavaScript, for the same reason the rest of HQ is server-rendered: the panel works before any script runs, arrow keys move between tabs for free, and there is no state to fall out of step with the markup. Each radio sits inside its tab's label, and the stylesheet reads which one is checked through `:has()`. The strip carries no tablist role: its children are radios, which assistive technology already announces as one group by their shared name, and a tablist owning no tabs would say otherwise. Each panel is its chart's own figure, so the strip stands over the frame of the one shown. {% endcomment %}
