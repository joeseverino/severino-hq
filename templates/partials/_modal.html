{% comment %} Modal: a dialog for one short, self-contained task. Host-private: a page's head action declares its dialog (`PageAction(modal=PageDialog(...))`) and page.html draws it; a host template may include this directly. The trigger must be a real link to a page that does the same job, so the surface still works when the dialog does not open: Import {% include "partials/_modal.html" with id="import" title="Import records" lede="Known files are skipped." body_template="app/_import_form.html" %} The opener stays a link, so a middle click or a new tab opens the full page, and app.js turns a plain press into `showModal()`; a `command` invoker would make it a button. The close button is the platform's own `command="close"` invoker, which needs no script. Opening fires the dialog's `toggle` event, where fragment.js fetches what the dialog holds back. An opener is one of four controls, each naming the dialog: a link with `data-modal-open=""`, a control with `aria-haspopup="dialog"` and `aria-controls="modal-"`, the platform's invoker, `command="show-modal" commandfor="modal-"` (partials/_about.html), or a popover's status with `data-origin="modal-"`. The browser gates and dev:look find a dialog's opener by those four alone (SELECTORS["dialog_opener"]), so a dialog opened any other way counts as one nobody can open. `body_template` is rendered with the surrounding context, a section in it heading itself under the dialog's title. Escape and the backdrop close the dialog; both are handled by the host, not by the caller. `size="wide"` draws a page in a dialog: two panels side by side, the window showing around it, scrolling inside itself under a title that stays put, and the whole screen on a phone. Without it the dialog is a form's width. `modal_class` names a dialog a sheet styles of its own (Command Center, an urgency's origin). `popover` draws it as a popover rather than a modal dialog, for a panel a script shows beside what opened it (`showPopover()`, partials/_urgency_pill.html), which a press elsewhere dismisses; its close button hides the popover. {% endcomment %} {% comment %} tabindex and autofocus together: the dialog moves focus inside itself on open, and without a target it lands on the close button and rings it. {% endcomment %}
