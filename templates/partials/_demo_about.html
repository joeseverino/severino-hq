HQ is the app one person runs a homelab from: its hosts, containers, certificates and DNS, and the agents that work on them. This demo shows it with sample data. The pages are HQ's own, saved as static files by the same build that CI and development run.

Things to try

  • Read the DNS change an agent is waiting for you to approve.
  • Open a container and follow it down to the host it runs on.
  • See what needs doing, and dismiss one.
  • Search from the header, or switch the theme in the menu.

What stays put

No server answers these pages, so a form that would change something says so and changes nothing. Dismissals and your theme are kept in this browser until you choose Reset demo in the menu.
