A disabled one, by any method, is never a link or a form: it stays in the tab order (`aria-disabled`) so its reason, the title, is read where it stands. One that names the view it is drawn on (a switch between views) is that view's state, `aria-current`, never a link to itself, unless it opens a dialog: then it is the dialog's one way in.
