{% comment %} One head control, from `action` (application.pages.PageAction), drawn by {% button %}. `extra` adds looks: the head renders a control twice, beside the title and in its menu, and this keeps both the same control. `heard` marks the copy beside the title, whose ask is heard there and seen on the head's reading line. A disabled one, by any method, is never a link or a form: it stays in the tab order (`aria-disabled`) so its reason, the title, is read where it stands. One that names the view it is drawn on (a switch between views) is that view's state, `aria-current`, never a link to itself, unless it opens a dialog: then it is the dialog's one way in.
